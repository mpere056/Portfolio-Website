## Decisions And Boundaries

- Components must not traverse raw relationship records.
- Public queries include only public nodes and reviewed public relationships.
- Hidden-discovery data requires an explicit discovered-ID set and never appears in tour output.
- Query ranking must be deterministic and explainable; do not add embeddings or graph-database infrastructure.
- Destination-facing adapters must resolve through the accepted destination registry and drop unsafe/unavailable targets.
