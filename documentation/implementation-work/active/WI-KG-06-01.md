## Acceptance

Firestore ingestion stores graph-safe metadata for every public chunk; retrieval accepts validated current public node context, performs a bounded reviewed-neighbor expansion or rerank without overwhelming direct query relevance, and returns stable public source descriptors. Unknown, private, or draft context falls back to ordinary retrieval, and no client identifier can inject factual prompt content.
