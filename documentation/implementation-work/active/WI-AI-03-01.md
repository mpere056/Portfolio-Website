## Acceptance

The global conversation sends only the current validated public semantic identifiers; the API rejects malformed context, resolves factual context server-side, passes at most the approved node ID into graph-aware retrieval, and returns visible public source descriptors through a structured companion channel. Unknown/private context falls back safely, direct user intent remains primary, source UI cannot navigate to unvalidated destinations, and `/chat` continues to work without context.
