## Runtime Composition

Revision 14 retains revision 13's cropped rendering and all 700 GPU particles, then adds a temporary on-page tuning console for creative review. Color plus 12 numeric LaserFlow controls now update existing shader uniforms without recompiling materials: horizontal/vertical sizing, wisp density/speed/intensity, flow speed/strength, fog intensity/scale/fall speed, decay, and falloff start. Values persist only in the reviewing browser and can be reset to authored defaults. The console is an evaluation instrument, not accepted final interface or final parameter evidence.

The structures themselves do not wobble. Reduced motion removes WebGL and preserves the particle-free fallback. Hidden tabs stop the render loop. Visible WebGL renders at `0.9x` DPR and 24 FPS idle or 36 FPS under attention; the overlay particle canvas runs at `0.8x` and 24 FPS. Particle travel remains vertex-shader owned, the three depths again total 700 points, flow fog uses three octaves, and the small orb uses detail level 3. Shader coverage is under four stage-equivalents per frame rather than roughly eight. The proof remains one viewport and is isolated from `/projects` and `/projects/ambient-proof`.

## Generation Record

Built-in image generation was used in edit/generation mode for five bounded outputs: a clean particle-free composite, an observatory-only magenta-key plate, an empty terrain field, a city-only green-key plate, and a portal-only magenta-key plate. Every prompt prohibited stars, dust, sparks, signal ribbons, waveforms, bloom, and floating particles; transparent plates were keyed locally with a soft matte, despill, and one-pixel edge contraction. No generated asset supplies runtime particle motion.
