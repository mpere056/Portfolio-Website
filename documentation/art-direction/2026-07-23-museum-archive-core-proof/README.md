# Museum Archive Core Proof

## Review Surface

- Route: `/projects/archive-core-proof`
- Primary region: `MUS-R07`
- Supporting regions: `MUS-R04`, `MUS-R05`, and `MUS-R06`
- Question: can the Museum's central authored-memory landmark feel materially alive without relying on a static focal image?

## Runtime Composition

The proof is code-first. A fragment-shaded atmospheric field replaces a static backdrop. The orbital core uses nested icosahedral shells, torus-knot structure, unequal rings, independent satellites, refractive material, and a changing interior light. The open book is fourteen separately deforming curved page leaves rooted at one spine, plus a shader-curled turning leaf. Its pop-up content cycles between an illuminated miniature city, a translucent crystal garden, and a rotating memory instrument. Eighteen miniature towers remain structurally fixed while procedural cyan and amber window fields change on unsynchronized clocks. A breathing doorway, volumetric threshold light, five depth-split tube currents with traveling pressure bodies, and 460 independently drifting particles connect the systems.

Pointer attention is local to the book, doorway, orbital core, current field, or proof-local refractive lens. The archive proof no longer mounts any raster-backed Museum membrane, aperture, or particle layer, so hover cannot reveal artwork from another district. Reduced motion and renderer failure show a stable code-authored checksum.
