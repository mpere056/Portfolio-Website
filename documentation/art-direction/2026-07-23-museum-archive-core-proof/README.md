## Runtime Composition

The proof is code-first. A fragment-shaded atmospheric field replaces a static backdrop. The orbital core uses nested icosahedral shells, torus-knot structure, unequal rings, independent satellites, refractive material, and a changing interior light. The open book is fourteen separately deforming curved page leaves rooted at one spine. Eighteen miniature towers remain structurally fixed while procedural cyan and amber window fields change on unsynchronized clocks. A breathing doorway, volumetric threshold light, five depth-split tube currents with traveling pressure bodies, and 460 independently drifting particles connect the systems.

Pointer attention is local to the book, doorway, orbital core, or current field. The accepted production Museum membrane, aperture, mesh, veil, and particle response remain above the route compositor. Reduced motion and renderer failure show a stable code-authored checksum; the original Museum artwork is used only as the hover-effect mask and never as the visible animated focal scene.
