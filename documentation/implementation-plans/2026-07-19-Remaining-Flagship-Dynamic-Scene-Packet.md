# Dreamlife And Sudoku Dynamic Scene Packet

Last updated: 2026-07-19

Status: implemented candidate under `ART-09`; local verification passes, Production and Mark acceptance remain.

## Route Ownership

Dreamlife and Sudoku share lifecycle inputs only. Dreamlife uses CSS-masked nacre fragments and SVG loop paths driven by selected future, reaction, and depth. Sudoku uses DOM grid state, coral/mint ownership material, SVG sync/version paths, and architecture boundaries driven by selected cell, real synthetic move state, computer participation, and depth. Neither route uses the Museum particle composition or LifeInbox receiving-vessel choreography.

## Dreamlife

- Stable checksum: approved nacre future-field artwork and existing path/reaction/product loop.
- Layers: matte, Current, Fallback, Wild Card, reaction prism, recombination loop, evidence.
- Causal states: selected future chooses the active fragment; resist/curious/pull changes refraction; Enter partially recombines; Understand completes the revisable loop and evidence.
- Calm/failure: reduced/hidden state stops SVG travel and fragment transforms; matte, paths, controls, and evidence remain.

## Sudoku

- Stable checksum: approved diagram-organism artwork and existing playable synthetic board.
- Layers: matte, grid, visitor trace, computer trace, sync wave, architecture boundaries, evidence.
- Causal states: selected cell moves the inspection plane; visitor/computer ownership changes coral/mint material; computer join activates version propagation; Enter/Understand expand architecture depth.
- Truth correction: the synthetic participant can no longer steal ownership when it considers an already occupied visitor cell.
- Calm/failure: reduced/hidden state stops sync travel; board state, ownership colors, paths, architecture, controls, and source remain.

## Renderer Decision

Both routes use DOM/CSS and SVG. No Canvas or WebGL is selected: Dreamlife needs authored refraction/recombination rather than simulation, and Sudoku needs precise state traces rather than fluid material.
