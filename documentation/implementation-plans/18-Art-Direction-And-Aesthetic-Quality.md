## Why This Plan Exists

The implemented ideas are structurally unusual, but the current visual execution can still read as an average polished portfolio: dark gradient, large serif heading, repeated rounded cards, faint borders, pills, glow, and dashboard-like panels. Those ingredients are not inherently wrong. The problem is that they have become the composition rather than supporting a more authored object, spatial idea, or material world.

The previous plans named taste and project identity, but mostly evaluated them at the end. That is too late. A technically complete interaction can already be visually committed to a generic structure before creative review occurs.

Art direction is therefore a build input and tracked capability, not decoration or a final polish pass.

## Live Audit: 2026-07-18

The audit does not reopen Phase 3's contracts, logic, content, routing, deployment, or rollback evidence. It reopens the creative dimension of `QA-02` and records the following aesthetic debt:

- The nine project signals are a regular three-column set of similarly sized rounded rectangles. Offset rows and glow do not change the underlying card-grid reading.
- Project identity is mostly communicated by title and accent color rather than silhouette, object, material, behavior, or composition.
- The selected LifeInbox depth is contained inside another rounded dark panel and resolves into familiar form, button, tab, and mini-card patterns.
- Large serif type and uppercase monospaced labels carry too much of the atmosphere. They create a style, but not yet a distinctive world.
- Darkness sometimes lowers legibility without creating a meaningful conceal/reveal relationship.
- Repeated border radii, thin borders, chips, and pills make unrelated systems feel like one interface kit.
- The Quick Tour, sound invitation, AI control, navigation control, and page content compete as floating interface furniture.
- The current calm state is sparse, but not always composed; empty space needs tension, direction, or an implied object rather than simply reduced opacity.

## Aesthetic Thesis

The portfolio should feel like an authored world of working instruments, memories, and systems, not a gallery of interface containers.

Visitors should first perceive:

1. A composition.
2. An object, trace, or disturbance.
3. A possible action.
4. Explanatory interface only when it becomes useful.

The interface should feel discovered from the content rather than placed on top of it.

## Non-Negotiable Principles

### Object Before Container

Every primary scene needs a focal artifact, field, mechanism, trace, or typographic object. A rounded panel cannot be the principal visual idea.

### Composition Before Component Reuse

Shared code may manage state and accessibility, but layout should not default to equal cards, symmetrical columns, or repeated section templates. Each major scene needs one dominant composition and a deliberate reading path.

### Material Before Decoration

Color, texture, reflection, line, shadow, and sound should imply a material world. Glow and blur are not substitutes for material. Every major effect must answer what is emitting, reflecting, concealing, or transmitting it.

### Darkness Must Have Causality

Darkness hides something specific and interaction reveals it. Important text and controls cannot simply be dimmed to manufacture mystery. The visitor should understand what changed and why.

### One Dominant Gesture

Each depth scene should have one memorable action or transition. Secondary controls should become quieter or spatially subordinate.

### Project Dialect, Shared Grammar

The five depth stages create cohesion. Projects do not need the same card shapes, colors, transition curves, or layout. Identity should survive if project names and logos are temporarily removed.

### Restraint Is Not Plainness

High-class visual restraint depends on exact proportion, material contrast, typography, negative space, and timing. Removing detail without strengthening composition produces emptiness, not refinement.

### Evidence Is Part Of The Art Direction

Architecture, source material, and project state should appear as authored artifacts: traces, layers, annotations, specimens, receipts, or diagrams. They should not default to a generic documentation panel.

## Explicit Rejection List

A milestone returns to art direction when it depends on several of these without a stronger authored idea:

- Equal card grids as the primary navigation composition.
- A dark rectangle inside another dark rectangle as the main depth transition.
- Repeated `rounded-2xl` or pill shapes across conceptually different objects.
- Technology-chip clouds used as visual filler.
- Generic radial-gradient glow or blurred color orbs without a semantic source.
- Large editorial serif type used as the only signal of sophistication.
- Uppercase monospaced eyebrow labels repeated at every level.
- Dashboard tabs, progress steppers, or segmented controls representing depth by default.
- Uniform fade-and-rise entrances for every object.
- Decorative particles unrelated to a graph edge, interaction, sound, or project behavior.
- A composition that would still work unchanged after swapping project names and accent colors.

These are rejection prompts, not a ban on individual CSS properties. A pill can be correct for a compact control; it should not become the site's universal object language.

## Shared Visual Grammar By Depth

| Depth | Aesthetic responsibility | Failure mode to avoid |
| --- | --- | --- |
| Signal | Create a distinct silhouette, rhythm, trace, sound, or material disturbance | Nine dim versions of the same card |
| Approach | Reveal the central artifact and one clear tension | A standard title-summary-tech stack |
| Handle | Let the visitor manipulate the project's real metaphor | A generic form placed in a themed panel |
| Enter | Change the spatial or perceptual rules enough to feel inside the system | More content appearing below the same container |
| Understand | Transform behavior into evidence, tradeoff, and connection | A row of architecture cards followed by links |

## Museum Art Direction

The museum lobby should feel curated without becoming a literal institutional museum.

### Required Changes

- Replace the uniform three-by-three card reading with a field of distinct signals. Signals may be typographic, diagrammatic, object-like, animated, or partially concealed, but need recognizable silhouettes.
- Create hierarchy among projects without implying a numerical ranking. Flagships may occupy stronger spatial anchors; historical projects may cluster as an archive drawer, shelf, strip, or related collection.
- Use the knowledge graph to create a few meaningful sight lines rather than decorating every item with equal glow.
- Make selection alter the composition: neighboring signals, light, depth, or framing should respond to the selected project's relationships.
- Consolidate utility controls into a quiet instrument rail or context surface so they do not compete as unrelated floating bubbles.
- Preserve a beautiful sound-off, reduced-motion state with intentional still composition.

### Museum Swap Test

Temporarily remove names and accent colors. A reviewer should still be able to distinguish the LifeInbox, Dreamlife, Sudoku, creative coding, and historical Discord regions from silhouette and behavior. If not, the composition is still too generic.

## Project Material Dialects

These are starting constraints, not final mood boards.

### LifeInbox

- Core metaphor: a trusted receiving instrument, not a productivity dashboard.
- Possible materials: dark lacquer, warm paper, ledger lines, stamped timestamps, small brass or amber mechanical signals.
- Motion: capture should feel immediate and physically settled; sync and enrichment should occur as later layers crossing visible boundaries.
- Evidence: local row, dirty state, server handoff, and reminder return can appear as one trace moving through a mechanism.
- Avoid: chat-input styling, generic kanban/task cards, green success cards, and a horizontal architecture tab row.

### Dreamlife

- Core metaphor: futures refracting from one present tension.
- Possible materials: translucent paper, lenticular layers, soft projection, mirrored or prismatic edges, authored handwriting or editorial marks.
- Motion: paths should diverge, react, and recombine rather than appear as three ordinary option cards.
- Evidence: the loop between Vision, Explore, and Refine should be spatially felt before it is diagrammed.
- Avoid: wellness-app gradients, generic pastel cards, horoscope imagery, and over-romantic dream clouds.

### Sudoku Together

- Core metaphor: a shared logical surface with another presence leaving precise traces.
- Possible materials: porcelain or paper grid, graphite marks, Discord-like presence light used sparingly, crisp numerical rhythm.
- Motion: the computer participant should have timing, hesitation, and a visible contribution path without pretending to be human.
- Evidence: embedded activity, proxy, persistence, and version boundaries can unfold from the board's edges.
- Avoid: a generic neon game dashboard, casino effects, confetti-first completion, or a stock Sudoku web app inside a card.

## Typography

Typography needs distinct roles rather than one repeated premium-dark formula.

- Display type establishes emotional voice only at major thresholds.
- Reading type handles explanatory content without becoming visually timid.
- Monospaced type is reserved for machine state, coordinates, timestamps, or authored technical notation, not every eyebrow label.
- Scale contrast should be meaningful; not every section needs a huge heading followed by muted body copy.
- Project dialects may introduce a limited secondary typographic behavior while preserving site-level readability.
- Line length, rag, spacing, and alignment are reviewed as composition, not left to component defaults.

Final font selection remains part of the chosen direction and requires rendered comparison, not font-name preference alone.

## Motion And Temporal Composition

Motion is designed as a sequence of beats:

1. Anticipation: the world signals that an object can respond.
2. Causal action: the visitor's manipulation produces a legible physical or spatial change.
3. Settlement: the scene reaches a composed state where meaning can be inspected.

Every motion review records:

- What caused it.
- What changed.
- What the visitor learned.
- What remains in reduced motion.
- Whether sound adds meaning or merely decoration.

Do not use the same easing, fade distance, and duration everywhere. Shared motion grammar should feel related, not cloned.

## Art-Direction Workflow

No major visual surface moves directly from wireframe logic to production styling.

1. Write a one-sentence emotional and interaction thesis.
2. Assemble a small reference matrix by quality: material, composition, typography, motion, and atmosphere. Do not copy a whole reference.
3. Create three deliberately different static keyframes for the same exact content.
4. Run the rejection list and select one direction with a written reason.
5. Produce Signal, Approach, and one deepest-state keyframe before component styling expands.
6. Build one representative interactive moment with real typography and approximate materials.
7. Capture stable desktop frames in calm and standard stimulation.
8. Review with Mark before multiplying the visual system across projects.
9. Implement shared primitives only after two scenes prove that they are genuinely shared.
10. Re-run functional, performance, calm-path, and fallback gates after aesthetic integration.

Placeholder visuals must be visibly labeled in tracking and cannot receive accepted creative status.

## Creative Review Record

The `Q` dimension cannot be accepted from a statement such as “looks good” or “visual checkpoint reviewed.” Each accepted major surface records:

| Review | Required question |
| --- | --- |
| Thesis | What should this scene feel like, and why does that fit Mark or the project? |
| Focal hierarchy | What is seen first, second, and only after interaction? |
| Silhouette | Is the scene recognizable without copy and accent color? |
| Material | What appears to be made, emitted, reflected, or concealed? |
| Distinctiveness | Would swapping content reveal that this is a reusable template? |
| Interaction | Does the visual response make the product idea clearer? |
| Typography | Do type choices and spacing carry authored voice without doing all the aesthetic work? |
| Calm state | Is sound-off and lower stimulation still fully composed? |
| Deep state | Does increasing depth change the experience rather than append more panels? |
| Restraint | What was intentionally removed, and did composition become stronger? |

Evidence includes the selected keyframes, at least one rejected alternative, stable browser captures, a short rationale, and Mark's acceptance for taste-sensitive milestones.

## Diagnostic Tests

These are manual, repeatable prompts rather than numeric scores:

- **Squint test:** the focal hierarchy remains clear when details blur.
- **Silhouette test:** project regions remain distinguishable without names and colors.
- **Swap test:** replacing one project's copy with another breaks the composition, proving it is not a template.
- **Crop test:** a representative crop looks authored rather than like a generic component library.
- **Darkness test:** concealed content has a discoverable cause and essential information remains legible.
- **Stillness test:** pausing motion leaves a strong composition.
- **Deepening test:** Handle, Enter, and Understand produce perceptual as well as informational depth.
- **Furniture test:** utility controls form one hierarchy and do not look like unrelated floating widgets.
