# Content And Route Inventory Baseline

- Captured: 2026-07-14
- Baseline commit: `7b99008cb28b994a3401ff20725b6c8e06f70039`
- Package: `BAS-02`
- Capability: `CAP-BAS-002`

## Purpose

Establish a reviewed, repeatable inventory of the authored content that will become the portfolio knowledge graph. This baseline distinguishes authored identity, runtime identity, AI-ingestion identity, loader coverage, and content destinations before `ARC-01` defines the stable namespaced-ID policy.

This package does not rename content, assign new IDs, change authored claims, repair ingestion, or redesign visitor routes.

## Reproduction

```powershell
$env:PATH=(Resolve-Path '.tools\node').Path+';'+$env:PATH
& '.tools\node\npm.cmd' run inventory:content
& '.tools\node\npm.cmd' test
& '.tools\node\npm.cmd' run build
```

Use `npm run inventory:content -- --json` for machine-readable output. The command exits nonzero when structural errors are found; known baseline gaps are reported as warnings or information until their owning package changes the policy.

## Identity Findings

1. Raw identifier `dreamlife` exists in both `about:dreamlife` and `project:dreamlife`. This is valid only if stable IDs remain namespaced.
2. Runtime and retrieval identity are already separate systems for every About entry.
3. Four miscellaneous documents have no authored identity and silently depend on filenames.
4. Three public blog posts are absent from the current retrieval corpus.
5. Project subdomain identity has a third mapping layer: subdomain to project slug in `PROJECT_SITES`.
6. There are no duplicate candidate keys within the proposed category/site namespaces and no missing required fields in runtime-loaded content.

## Downstream Handoff

### `ARC-01` Stable ID Policy

- Define namespaced IDs at minimum for project, event, misc/document, and site-scoped post nodes.
- Decide whether route slugs remain mutable presentation fields distinct from stable IDs.
- Assign authored identity to the four filename-only miscellaneous files.
- Define aliases or migration behavior before changing the 20 About retrieval slugs.
- Preserve the valid project/About `dreamlife` overlap through namespaces.

### `KG-01` Shared Loader Parity

- Replace independent traversal assumptions with one recursive content discovery layer.
- Preserve current rendered output while making blog posts available to graph and retrieval consumers.
- Remove runtime/ingestion identity divergence only after the stable-ID contract exists.
- Retain the inventory command as a regression check.

### `KG-02` Schema Validation

- Convert the baseline required-field rules into shared validated schemas.
- Add relationship, visibility, lifecycle, version, and source metadata incrementally.
- Keep raw authored content review separate from derived graph compilation.
